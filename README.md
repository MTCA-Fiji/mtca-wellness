# MTCA Wellness Weight Challenge App

A secure staff wellness app designed to support the MTCA Weight Challenge by helping staff register, record weigh-ins, and track their health progress.

## Purpose

The app supports workplace wellness by providing a simple digital platform for staff participation, progress tracking, and administrator-managed reporting.

## Key Features

- Google account sign-in
- Staff registration
- Baseline weight recording
- Weekly weigh-in entries
- BMI category tracking
- Personal progress dashboard
- Privacy-conscious leaderboard
- Administrator access for reporting and oversight
